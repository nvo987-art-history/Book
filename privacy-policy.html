Privacy Policy

1.1. General provisions

NVO987 is an independent artistic, cultural, research and publishing initiative engaged in research, art history, visual culture and publications.

NVO987 respects the privacy of website visitors and is committed to processing personal data only where lawful and necessary.

This policy explains what data processing practices apply to visitors in connection with the operation of the www.nvo987.us website.

1.2. Data controller

The data controller:

Nicholas Van-Orton
Email: nvo@nvo987.us

1.3. Data collection on the website

The NVO987 website does not itself operate a system designed for collecting user data.

The website currently does not have:

  • user registration;
  • user accounts;
  • contact form;
  • commenting system;
  • newsletter subscription;
  • online payment system;
  • online purchasing system;
  • Google Analytics;
  • Google Ads or remarketing;
  • Meta Pixel;
  • visitor profiling;
  • advertising tracking;
  • behavioral tracking;
  • other analytics or tracking services.

Therefore, NVO987 does not collect users' names, email addresses or other personal data for its own purposes during simple browsing of the website.

1.4. Contact by email

Contact may be initiated through the email address provided on the website: nvo@nvo987.us.

If a visitor sends an email, the personal data voluntarily provided in the email — such as name, email address or the content of the message — may only be used to respond to the inquiry and to manage the relevant communication.

NVO987 does not use this data for advertising profiling or behavioral tracking.

1.5. Technical data and server logs

The technical infrastructure used to operate the website may, in certain cases, automatically process technical information.

Such information may include, for example:

  • IP address;
  • date and time;
  • browser type;
  • operating system;
  • technical access data;
  • information related to server errors.

These data are not used by the website operator for advertising, profiling or visitor tracking purposes.

Some technical data processing may be carried out by service providers providing the website infrastructure in connection with the operation, security and logging of their own systems.

1.6. Hosting and technical services

As part of the website's technical infrastructure, GitHub is used.

GitHub may process technical data in the course of operating its own service. Such data processing is subject to GitHub's own privacy and service terms.

NVO987 does not use GitHub for visitor profiling, advertising tracking or marketing data collection.

1.7. External websites

The NVO987 website may contain links to external websites and services, such as external sales pages related to books.

In connection with the sale of books, external services, including Lulu, may be used.

External websites operate according to their own privacy policies and technical systems. NVO987 does not control or direct the data processing practices of these external services.

If a visitor proceeds to an external website, the privacy policy of the relevant service provider shall apply.

1.8. Data security

NVO987 strives to process personal data under its own control appropriately and securely.

Since the website does not have user registration, a database-based user profile system or an online data collection system, data processing associated with such systems is currently not part of the operation of the website.

1.9. Changes to the Privacy Policy

This Privacy Policy may be amended in the event of changes to the functions of the website or the technologies used.

The current version will always be published on this page.

NVO987 does not use any third-party analytics or advertising tracking system on its own website.

If the website introduces analytics, advertising, profiling or other cookie technologies that are not currently used in the future, this Cookie Policy will be updated accordingly.
